# Пит-радар

Браузерное приложение для командного картингового марафона на live-тайминге Kart Chrono (Стайки). Оно отслеживает каждый физический карт через FIFO-очереди коридоров A/B, копит рейтинг карта по всем его стинтам и подаёт сигнал, когда быстрый карт уходит в пит-лейн.

Всё приложение — один файл `index.html`, без сборки и без сервера. Данные идут напрямую из WebSocket `wss://kartchrono.com:9180`; подключение с другого домена работает (проверено).

## Как открыть

**Вариант 1 — хостинг (лучший для телефона, работает и на iPhone).** Выложите `index.html` на любой статический хостинг: GitHub Pages, Netlify, Cloudflare Pages. Откройте ссылку на телефоне и добавьте на главный экран. Состояние хранится в `localStorage` этого адреса, так что перезагрузка страницы ничего не ломает.

**Вариант 2 — файл на Android.** Скопируйте `index.html` на телефон и откройте его в Chrome через «Файлы». Работает без интернета, но для live-данных нужна сеть.

**На компьютере** достаточно открыть файл двойным кликом.

Библиотека SortableJS (перетаскивание картов) и шрифт грузятся с CDN. Если они не загрузятся, всё работает, только без drag-and-drop: карты двигаются кнопками в шторке карта.

## Как пользоваться в гонке

1. При первом открытии — модалка «Старт гонки»: номер нашей команды и сколько свободных картов в коридорах A и B на старте.
2. Экран **Пит-лейн**:
   - Каждый PIT IN появляется карточкой «№12 WRW в питах — карт S12: лучший −0.8 с, средний −0.5 с».
   - Нажмите **A** или **B** — коридор, который софт назначил команде. Неразмеченные питы стоят по хронологии; размечайте сверху вниз.
   - Если в пит-лейн уходит быстрый (зелёный) карт другой команды — звук, вибрация и вспышка. Звук включается после первого касания экрана.
   - Блок «Если заедем сейчас»: головы обоих коридоров и вердикт.
   - Коридоры: сверху голова (выдаётся следующим). Карт можно перетащить (долгое нажатие) или нажать на него: метка (номер на кузове), перенос в голову/хвост, удаление. «+ карт в хвост» добавляет новый карт.
   - После нашего пита — плашка «Мы получили карт B2 — быстрый/медленный».
3. **Трасса** — все команды, их текущий карт, таймер стинта от последнего PIT IN с полосой до 35 мин, блок «Скоро в пит» (≥ 30 мин жёлтый, ≥ 33 мин красный). Нажатие на команду: «Замена карта на трассе (поломка)» и «Отметить PIT IN вручную», если тайминг пропустил пит.
4. **Карты** — рейтинг, история стинтов, где карт сейчас.
5. **↶** в шапке — отмена последнего действия (разметка, правка, ложный пит).

Имена картов: `S9` — стартовый карт команды №9, `A1/B2` — стартовые карты в коридорах, `R…` — выданный на трассе при поломке, `N…` — добавленный вручную, `?…` — карт, полученный в неразмеченном пите.

## Метрики

- Эталон в момент круга — медиана кругов всех команд за последние 5 минут (окно меняется в настройках). Поэтому дождь и смена темпа поля не ломают сравнение.
- Чистый круг: не пит-ин/пит-аут, не удалённый, не первый, не рядом с питом, не медленнее эталона больше чем на 10%.
- Стинт: лучший и средний по чистым кругам (дельта в %; секунды пересчитаны в текущий темп). В рейтинг идут стинты с ≥ 3 чистыми кругами.
- Рейтинг карта — взвешенно по числу чистых кругов. С «поправкой на команду» из дельты стинта вычитается средняя дельта этой команды; так отделяется быстрый карт от быстрого пилота.
- Цвета — перцентили среди всех картов: 33% лучших зелёные, 33% худших красные (настраивается).

На симуляции 5-часовой гонки с дождём рейтинг совпал с истинной скоростью картов с ранговой корреляцией 0.99 (с поправкой на команду) и 0.91 (без неё).

## Тест без живой гонки

**Настройки → «Тест без живой гонки».**

- **Симуляция 5 ч** — мок-гонка из 13 команд со скрытой скоростью картов, случайными коридорами, пит-стопами по регламенту и дождём (темп 1:05 → 1:14.5 → 1:06.5). Она выдаёт сообщения ровно в протоколе Kart Chrono, так что проверяется и разбор данных. Ускорение — поле «Ускорение».
  - «Подсказка истинного коридора» показывает на карточке, куда на самом деле заехала команда. Так можно быстро размечать и проверять FIFO.
  - На экране «Карты» видна «истина» — реальная скорость карта в симуляции.
  - «Симуляция шлёт коридор в поле 62» проверяет автоматическую разметку.
- **Запись живого потока** — «Начать запись» на любой живой гонке Kart Chrono, потом «Скачать запись». «Реплей файла записи» прогоняет её в ускоренном времени. Для тренировки подойдёт любой трек Kart Chrono с командной гонкой: подставьте его `trackId` в настройках. Его видно в исходнике страницы `https://<трек>.kartchrono.com/online/` (`var trackId = "..."`).

Архив Стаек (`/archive`) закрыт и всегда редиректит на главную, поэтому прогнать прошлую 10-часовую SWS не получилось.

## Что найдено в протоколе Kart Chrono

Клиент шлёт `{"trackId":"da5ce291c3fbb8feb31d79bdee1a00b7"}`, сервер отвечает:

- JSON-снимок с `command:"clear"`, потом JSON-диффы. Поля участника в `results[competitorId]` — числовые коды: 3 номер, 26 команда, 4 пилот, 5 состояние, 10/11/12 три последних круга, 13 круги, 27 питы, 28 время пита, 29 время сессии, 32 средний круг сессии, **62 PIT_LANE_SELECT**.
- Состояние участника (поле 5): `6` = PIT-IN, `7` = PIT-OUT. Это самый ранний сигнал пита.
- Бинарные пакеты `BINLAPS:` — круги по 52 байта: id участника, id круга, номер, время круга, метка времени, флаги (`0x400000` PIT-IN, `0x800000` PIT-OUT, удалённый/отклонённый).
- Время гонки: `100` (прошло, с), `101` (осталось, с), `106` флаг (2 красный, 3 финиш). Таймеры стинтов идут по `100` — на красном флаге они встают.
- `changes` — смены пилотов, `comments` — блок ИНФОРМАЦИЯ (пишется в лог).

## Если на гонке формат окажется другим

Всё, что зависит от формата, — в начале `<script>` в `index.html`:

- `F`, `ST`, `FLAG`, `LF` — коды полей, состояний, флагов. Взяты из `https://stayki.kartchrono.com/js/dataPullerWS2.js`. Если сайт обновится, сверьте с этим файлом.
- `KC.diff()` — разбор участника: пит по полю 5, запасной сигнал по росту счётчика питов (27), коридор из поля 62, запасной сбор кругов по полю 13.
- `KC.binRec()` — разбор бинарных кругов и сигнал пита по флагу круга.
- `normLane()` — как значение поля 62 превращается в A/B. Сейчас `A/А/1/L` → A, `B/Б/В/2/R` → B.

**Не проверено на живых данных:** что именно лежит в поле 62. На Стайках это поле не выводится в табло, а живой командной гонки во время разработки не было. Если коридор там не появится — размечайте кнопками, всё остальное от этого не зависит. Если появится в другом виде (например, номер коридора 0/1) — поправьте `normLane()`. Чтобы разобраться, включите запись потока и посмотрите в файле, что приходит в поле `"62"`.
